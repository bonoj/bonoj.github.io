# Denial — Exclusive Device Registry

Public page: https://bonoj.github.io/jit/denial/

A static satirical compatibility assessment whose only actual outcome is denial. The service claims to support exactly one authorized physical device, but no device is admitted.

## Contract
- Standalone `index.html`; no external assets, backend, cookies, network requests, tracking, or build process.
- All visitors receive the same denial, including the author's device.
- Reassessment increments a local counter without changing eligibility.
- Technical determination reveals a deterministic record, not an admission path.
- Nested policy/inspection/evaluation/attestation functions are deliberately ceremonial. The decisive predicate is false for every input.
- The public-facing experience stays in character; this README explains the experiment.
- Never add a real secret or device fingerprinting to this joke.
