# Pigment Fields

Goal: animated geometry supports illustration without dominating perception. Explore selective edge loss, pigment coverage and temporal coherence before neural diffusion.

## Experiment 01

[Animated pigment fields](experiment-01.html) — preserved chat shader, WebGL2 ray-marched spheres, object-local multiscale noise, silhouette coverage and smooth SDF union. Controls: raw/illustrative, pause, reset, edge, pigment, merge. Standalone wrapper and minimum resize guard added. No actual pigment diffusion or neural inference. User found the chat version fun; standalone runtime not independently verified.

## Experiment 03

[Material permeability](experiment-03.html) — preserved chat shader with independent geometric union and procedural material ownership, warped branching invasion, permeability, fusion and turbulence controls, three diagnostic modes. User found it very interesting. No persistent pigment transport; standalone runtime not independently verified. Experiment 02 was rejected and not archived.

## Experiment 04

[Jovian atmosphere](experiment-04.html) — preserved chat shader with differential zonal motion, thermal and condensation fields, material boundary mixing, four prescribed vortices, six controls and four instrument views. User found it interesting but observed that storms are immediately shredded and smeared, overwhelmed by the bands. Preserve this flaw as a baseline. Coriolis is not dynamically integrated; fields are kinematic, not conserved or persistent. Standalone runtime not independently verified.
