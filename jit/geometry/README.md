# JIT Geometry

A home for small, standalone executable explorations of composable geometry, motion, and image-making.

## Initial toys

- `murmuration/` — boids, flocks, schools, and responsive swarms
- `mirror/` — reflections and geometric constraints
- `topology/` — connected lattices and continuous deformations (cup ↔ torus)
- `pigment/` — trajectories as persistent drawing

## Working principles

- Each toy is independently executable and mobile-first.
- Keep simulation state independent of 2D/3D rendering.
- Extract shared primitives only after a toy proves their usefulness.
- Prefer direct manipulation over UI, menus, or instructions.
- Do not copy or publish contributed artworks without permission.

This directory is a playground, not yet a shared engine.
