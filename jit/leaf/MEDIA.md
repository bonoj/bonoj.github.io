# Leaf — Visual reference and media manifest

Status: **discovery, not downloaded or embedded**. Image search results are candidate source pages; each chosen image needs its actual file URL and placement/crop inspection. ## Direction
Mature banana plants; heavy arched midribs, split drooping blades, wind-torn edges, luminous translucent green. Editorial photography with a sense of scale. Side-on leaf silhouette, not top-down botanical diagram. No water-droplet logo gimmick.
