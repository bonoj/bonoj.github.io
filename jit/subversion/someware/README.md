# SOMEWARE — Current build

Live: https://bonoj.github.io/jit/subversion/someware/

Inherits all seven design invariants from [Subversion](../README.md).

## Experience
Exactly two near-full-viewport scenes separated by a thin white-to-black threshold. No editorial sections, plans, accounts, or extra navigation. White landing: outlined cloud, SOMEWARE, “It's in a better place.”, Null Point Technology™, free infinite preservation, anchor to functionality. Black experience: white-lensed black hole, Galactic-Class Storage Facilities™, local file picker, preserve action, confirmation and reference.

## Imagery
White hero chooses one of three linked architectural photographs at random on each load; fallback tries the next if one fails. Black hero always uses the third selected black-hole candidate (silver-white accretion disk). Preserve the full subjects on mobile: `object-fit: contain` and soft background/gradient integration, not aggressive cover crops. The white image fades into white at the bottom; black emerges from black at the top. Transition is thin, not an extended grey section.

## Interaction
File metadata is inspected locally for the temporary selection only. Never read, transmit, store, or log file contents. On preservation, release references and show a locally generated receipt. No backend, no subscriptions, no checkout, no real archival claims in implementation documentation. Public copy stays in character.

## Follow-up QA
Check image availability/hotlink restrictions, licensing, narrow and wide renders, image placement, touch/focus and no horizontal overflow. Current images are externally linked references rather than bundled assets.
