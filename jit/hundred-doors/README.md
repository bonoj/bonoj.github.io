## Working rules

1. Distinguish **connection-requested**, **connected**, **message-sent**, **replied**, **bounced**, and **formal application**. Clicking LinkedIn is not proof of any action.
2. Prioritize a single clear next action. Never suggest re-contacting a person with a sent message without reviewing status.
3. Don't fabricate personal profile links, familiarity with research, hiring influence, or current job openings.
4. Keep private correspondence, private Home notes, guessed emails and secrets out of public source. Publish only public professional links and brief outreach statuses already authorized for this tracker.
5. User's canonical work: https://bonoj.github.io/. Creative-world-building, experimental interactive systems, human–model collaboration. Avoid framing as conventional coding-only work.
6. Browser state is local. Observation export/import is an explicit handoff, not a background sync. Make this limitation visible.
