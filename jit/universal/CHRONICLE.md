# UNIVERSAL — CHRONICLE

## Phase 0 — 2026-11-04
Established deterministic PRNG, versioned film identity, canonical fifteen-function graph, macroplan fixtures, obligation ledger, event-sourced world state, and tests.

## Phase 1 — 2026-11-04
Created the first fifteen-scene Thriller screenplay fixture, Fountain export, and corpus tests. Its original single civic-records plot demonstrated why byte-level uniqueness is not semantic diversity.

## Phase 2 — causal architectures and replay — 2026-11-04
Replaced the single plot with three distinct authored causal mechanisms: **Exposure** (falsified public record), **Rescue** (flood evacuation crossing), and **Recovery** (sabotaged emergency broadcast). Each maps to the same fifteen dramatic functions but has a different concrete problem, obstacle chain, evidence, action and dialogue. Added nine typed world-state transactions per film, a replayable provenance ledger, and tests that regenerate 300 films and replay their event histories. A local Node 22 run passed: 300 films, architecture distribution 103 exposure / 89 rescue / 108 recovery, nine events per film.

**Known limitations:** three fixed fifteen-scene architectures are not thousands of independent films. Character names and dialogue are still minimally compositional; state transactions are associated with scenes but the action prose is not generated from the event ledger. Scene headings reuse one location; feature length, spatial continuity, natural dialogue, other genres, public reader, and Next are not implemented. The repo test suite is committed but not independently run from GitHub's remote bytes.

**Next:** derive scene text and participant locations from typed transactions, introduce per-character goals and conversation tactics, expand to a second distant genre, and test semantic distinctness rather than just script bytes.
