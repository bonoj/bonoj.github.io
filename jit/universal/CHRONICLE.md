# UNIVERSAL — CHRONICLE

## Phase 0 — 2026-11-04
Established deterministic PRNG, versioned film identity, canonical fifteen-function graph, macroplan fixtures, obligation ledger, event-sourced world state, and tests.

## Phase 1 — 2026-11-04
Created the first fifteen-scene Thriller screenplay fixture, Fountain export, and corpus tests. Its original single civic-records plot demonstrated why byte-level uniqueness is not semantic diversity.

## Phase 2 — causal architectures and replay — 2026-11-04
Replaced the single plot with three distinct authored causal mechanisms: Exposure (falsified public record), Rescue (flood evacuation crossing), and Recovery (sabotaged emergency broadcast). Each maps to the same fifteen dramatic functions. Added nine typed story transactions per film, a replayable provenance ledger, and tests for 300 deterministic film plans.

## Phase 2.1 — spatial scene state — 2026-11-04
The first public preview exposed an obvious shortcoming: all fifteen scenes used the same location even when the prose described movement. Introduced per-architecture scene location maps, INT/EXT headings, participant lists, and replayed `entersLocation` transactions. The corpus test now checks that every speaker is listed as a participant, scene headings match the location, and the event ledger reproduces the final state.

**Remaining limitations:** location changes are explicit but travel times and geography are not yet modeled; some dialogue assumes characters are together when the action suggests otherwise. Character actions and dialogue are still primarily authored per beat rather than derived from event transactions. Three fixed architectures are not thousands of movies. Scripts remain 15-scene fixtures; no feature-length claims. GitHub source has been committed, but the test suite has not been independently run against the committed remote bytes.

**Next:** plan actual scene participation and goals, then generate dialogue from conversation tactics constrained by those goals. A second genre adapter must prove the universal graph is not a Thriller-only abstraction.
