# UNIVERSAL

**Every story. The same story.**

Universal is a fictional film studio and a deterministic, recombinatorial screenplay engine. Every film shares a canonical narrative structure while genre, setting, characters, pacing, and dialogue transform its realization.

[System specification](SPEC.md) — narrative graph, causal state, genre adapters, screenplay AST, validation, and staged implementation.

## Status

Specification complete at v0.1. Engine and public site not yet implemented. The original `jit/average/` workspace has been migrated here.

## Identity

The public-facing brand is **UNIVERSAL**, not Universal Pictures. The engine is **The Universal Screenplay**. The studio's quality department suppresses excessive originality while maintaining coherent, conventionally competent screenplays.

This is an independent fictional creative experiment, not affiliated with the existing Universal Pictures studio.
